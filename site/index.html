One policy file controls what AI coding tools can read and edit. Personal data is redacted on your machine before any AI sees it. Nothing leaves your laptop.

Block & redact

Hide files from AI completely, or show redacted copies with PII replaced. Emails, phones, TFNs, ABNs, Medicare numbers, cards — validated with real checksums, not just regex.

Fake mode

Replace real data with realistic stand-ins: "Olivia Walker", fiction-range phone numbers, card numbers that fail Luhn. AI writes natural code without seeing real people.

Round-trip edits

When AI writes [EMAIL_1] into an edit, PawsOffOff swaps the real value back on your machine. The AI never sees the real data, but your files stay correct.

Local gateway

pawsoff run claude proxies all API traffic. Your prompts, file contents, and command output are scrubbed before they leave. Replies are restored before Claude acts on them.

PR check

A GitHub Action catches AI-written changes to protected files. It reads the hash-chained audit log, counts human approvals, and fails the check if the policy isn't met.

Local AI (optional)

Add local_model: "ollama:llama3.2" to catch names and addresses that patterns miss. Runs on your laptop — text never leaves the machine.

How it works

1

Define your policy

A single .pawsoff.yml file says which paths are hidden, redacted, review-required, or blocked. Commit it to your repo. The strictest matching rule wins.

2

PawsOffOff intercepts every AI tool

Free tier: hooks intercept tool calls from Claude Code, Codex CLI, and Aider before they read or edit files. Pro tier: a transparent network proxy intercepts ALL AI tools — Cursor, Copilot, Windsurf, ChatGPT — at the network level, no hook support needed.

3

Real data never leaves

PII is replaced with numbered placeholders or realistic fakes. The mapping lives in an encrypted local vault (AES-256-GCM). When AI writes a placeholder into an edit, the real value is swapped back locally.

4

Every decision is logged

A hash-chained ledger records what PawsOffOff did. The PR check reads it. You can give the evidence record to an auditor. pawsoff verify-log confirms it hasn't been tampered with.

The policy

One YAML file. Paths use gitignore-style patterns. When rules overlap, the strictest one wins. AI tools can never edit the policy itself.

version: 1
rules:
  - path: "secrets/**"
    ai_read: block                # AI can't see these at all
  - path: "customers/**"
    ai_read: redact               # PII replaced before AI reads
  - path: ".github/workflows/**"
    ai_edit: block                # humans only
  - path: "payments/**"
    ai_edit: review               # AI can edit after human approves
    reviewers: 2

redact:
  enabled: true
  mode: fake                      # or "placeholder" for [NAME_1] style
  # local_model: "ollama:llama3.2"  # optional local AI for extra detection
